# تلال ERP — نظام إدارة التسويق العقاري

نظام إدارة شامل لشركة تلال: عملاء (CRM)، وحدات عقارية، مبيعات وفواتير، محاسبة، وموظفين.

## التقنيات

- Next.js 14 + TypeScript + Tailwind CSS
- Supabase (قاعدة بيانات PostgreSQL + مصادقة)
- Vercel (النشر)

## التشغيل لأول مرة

افتح Terminal داخل VS Code (قائمة Terminal ← New Terminal) ونفّذ:

```bash
npm install
npm run dev
```

ثم افتح المتصفح على: http://localhost:3000

## هيكل المشروع

- `src/app/login` — شاشة تسجيل الدخول
- `src/app/dashboard` — لوحة التحكم (محمية)
- `src/lib/supabase` — الاتصال بقاعدة البيانات
- `src/middleware.ts` — حماية الصفحات وإدارة الجلسات
- `.env.local` — مفاتيح الاتصال (سري — لا يُرفع إلى Git)
